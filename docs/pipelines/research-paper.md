# research-paper

‹ back to [README](../../README.md#pipelines)

**research-paper** — turning a research direction into an empirical
systems/ML paper draft: scope → novelty (fans out, one agent per candidate
angle) → design → experiment (fans out, one agent per experiment) → analyze
→ draft → review → finalize. Fans out twice (per angle, per experiment) and
self-routes: design can hop back to re-scope or re-pick the angle, and
review can hop back to redesign, re-run experiments, or redraft. Adaptive:
it runs experiments when the workspace can measure the claim, and writes
from provided material when it can't. It refuses to fabricate — an
unwarranted paper ends in an honest
handback, not paper-shaped text — and hands back the figures and data only a
human should provide rather than faking them.
See [PAPERS.md](../../orchestra_engine/pipelines/research-paper/PAPERS.md).
